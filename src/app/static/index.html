Endpoints

Every route is a GET. Click one to try it.

  • GET/quotesAll quotes, with optional ?season= and ?search= filters
  • GET/quotes/randomOne random quote
  • GET/quotes/{id}One quote by id (1–125)
  • GET/seasons/{season}Every moral in a season (1–7)
  • GET/seasons/{s}/episodes/{e}The moral for one episode
  • GET/quotes?search=fearSearch the morals for a word

Usage

No key, no sign-up. Just ask.

# shell
curl https://clone-wars-quotes.jm2lilly.workers.dev/quotes/random

// JavaScript
const res = await fetch("/quotes/random");
const { quote, season, episode, title } = await res.json();
